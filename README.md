# Конструктор иллюстраций

Веб-редактор для сборки композиций из векторных объектов, предоставленных в Figma для тестового задания. Готовую композицию можно отредактировать, перекрасить и скачать в SVG.

**[Открыть редактор](https://eaojjm.github.io/illustration-composer/)**

**[Видеодемонстрация](demo-voiced-zoom.mp4)**

## Что умеет редактор

- Собирает композицию по списку названий объектов или подбирает их по теме, заголовку или метафоре.
- Позволяет перемещать, поворачивать, дублировать и удалять объекты, менять порядок слоёв и переключать роль объекта между главной и фоновой.
- Поддерживает горизонтальный, квадратный и вертикальный холст, а также исходные варианты детализации S и L.
- Автоматически перекрашивает композицию при выборе встроенной палитры или загрузке своей палитры в JSON.
- Экспортирует композицию в SVG с отдельной группой для каждого объекта.

## Быстрая проверка

1. Откройте редактор, выберите режим **«По теме или метафоре»**, введите «Подготовка к экзамену» и нажмите **«Собрать композицию»**. Редактор подберёт книгу, лампу и ручку.
2. В режиме **«По названиям объектов»** попробуйте «телефон, пазлы».
3. Выберите объект на холсте, передвиньте его и измените палитру.
4. Нажмите **«Скачать SVG»**. Чтобы проверить редактируемость, импортируйте файл в Figma и выделите группу одного объекта.

Для локального запуска скачайте `index.html` из репозитория и откройте файл в браузере. Библиотека встроена в HTML, поэтому для запуска достаточно одного файла.

## Как устроен проект

**Хранение и извлечение SVG.** Скрипт сборки на Python извлекает нужные SVG из архива Figma, проверяет используемые элементы и ссылки на области обрезки и встраивает библиотеку в HTML. В браузере редактор выбирает исходный вариант объекта по названию, детализации и роли.

**Сборка и редактирование.** В режиме по названиям редактор сопоставляет ввод с каталогом. Для тем используется словарь ключевых слов и заранее заданные наборы объектов. Если совпадений нет, редактор просит уточнить запрос. Оба режима используют один алгоритм раскладки с общим масштабом для сцены. Позиция, поворот, роль и порядок слоёв хранятся отдельно для каждого объекта композиции.

**Палитры и экспорт.** При смене палитры заливки и обводки меняются по цветовым ролям. Для своей палитры загрузите JSON с полями `background` и `accents`, по три HEX-цвета в каждом. Цвета в `background` идут от светлого к тёмному. При экспорте редактор сохраняет векторные контуры и группирует элементы по объектам.

Редактор работает в браузере на HTML, CSS и JavaScript. Подбор объектов, перекраска и экспорт выполняются локально, без внешних API.

## Полные исходники и примеры

В архиве `illustration-composer-submission.zip`, который передаётся вместе с заданием, находятся шаблон редактора `src/editor.template.html`, скрипт `build.py`, исходная SVG-библиотека и файл `example-palette.json`. Чтобы пересобрать автономный `index.html`, распакуйте архив и выполните `python build.py` из его корневой папки. Достаточно Python 3.

| Пример в архиве | Формат | Палитра |
| --- | --- | --- |
| `examples/learning.svg` · Обучение и развитие | Горизонтальный, L | Фиолетовая |
| `examples/technology.svg` · Телефон и пазлы | Квадратный, L | Бирюзовая |
| `examples/date.svg` · Свидание | Вертикальный, S | Персиковая |
